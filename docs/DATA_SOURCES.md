# Data sources: findings and plan

Investigated 2026-09-09. "Verified live" below means the source's download
endpoint or catalogue entry was confirmed current at that date. This session's
sandbox could only reach GitHub, npm and PyPI directly, so the OS, ONS and
doogal endpoints were confirmed through their public catalogue pages and
third-party documentation rather than by downloading from them here. The
pipeline was exercised end to end on a GitHub-hosted 2017 snapshot of the same
centroid data (see "Local test run" at the bottom).

## Summary

| Level     | Geometry in the app         | Source                                            | Status               |
|-----------|-----------------------------|---------------------------------------------------|----------------------|
| Unit      | Point (centroid)            | OS Code-Point Open (GB); ONSPD optional (adds NI) | Official, live       |
| Sector    | Polygon                     | **Derived** (Voronoi of units, dissolved, clipped) | Generated by pipeline|
| District  | Polygon                     | **Derived** (dissolved sectors)                    | Generated by pipeline|
| Area      | Polygon                     | **Derived** (dissolved districts)                  | Generated by pipeline|
| Coastline | Clip mask                   | ONS Countries boundaries (BGC, generalised 20 m)  | Official, live       |

There is **no official open dataset of postcode polygons at any level**. Royal
Mail and OS only sell them (OS "Code-Point with Polygons"). Every free polygon
set on the web is derived from the open unit centroids, so this project derives
them too, from the same open inputs and under the same licence chain, rather
than depending on a third party's derived download that cannot be regenerated.

## Unit centroids

### OS Code-Point Open (chosen default)

- Download: `https://api.os.uk/downloads/v1/products/CodePointOpen/downloads?area=GB&format=CSV&redirect`
  (OS Downloads API, no key). Product catalogue: https://osdatahub.os.uk/downloads/open/CodePointOpen
- ~1.7 million live postcodes for England, Scotland and Wales. Not included:
  Northern Ireland, Isle of Man, Channel Islands.
- Updated quarterly (Feb, May, Aug, Nov). CSV zip ~20 MB; 120 files (one per
  area), no header row. Coordinates are OSGB36 British National Grid
  (EPSG:27700); the pipeline reprojects to WGS84.
- Licence: Open Government Licence v3. Required attribution:
  `Contains OS data © Crown copyright and database right <year>` and
  `Contains Royal Mail data © Royal Mail copyright and database right <year>`.
- Positional quality indicator 90 means "no coordinates" (non-geographic
  postcodes, PO boxes); the pipeline drops those rows.

### ONS Postcode Directory, ONSPD (optional, adds Northern Ireland)

- Catalogue: https://geoportal.statistics.gov.uk/ (search "ONS Postcode
  Directory"). Latest editions seen: February 2026 and May 2026; a new edition
  appears each quarter. Zip ~235 MB, one CSV of all UK postcodes, live and
  terminated.
- Licence: OGL v3 for Great Britain. **Northern Ireland (BT) postcodes are
  not OGL**: they are covered by a Northern Ireland End User Licence from Land
  and Property Services, which permits internal business use only; commercial
  or public redistribution needs a separate licence from LPS. A public web map
  built from BT postcodes would need that licence.
- The pipeline supports ONSPD as an input format and excludes BT rows unless
  `INCLUDE_NI=1` is set explicitly.

## Polygon candidates that were investigated and not used

- **doogal.co.uk** (`/PostcodeDownloads`, `/PostcodeDistricts`,
  `/KmlDataFeeds`): publishes district and sector KML for the whole UK. The
  author documents that they are built by dissolving unit-level Voronoi
  polygons in QGIS, i.e. the same method as this pipeline. Downloads are
  behind a browser page rather than a stable versioned URL, there is no
  changelog, and the licence is inherited rather than stated per file. Kept as
  a documented alternative input (`pipeline/README.md`), not the default.
- **missinglink/uk-postcode-polygons** (GitHub): KML/GeoJSON of areas and
  districts traced from Wikipedia maps. Hand-drawn, approximate, CC BY-SA 3.0
  (a share-alike licence that does not mix cleanly with OGL), and no sectors.
- **Geolytix Postal Boundaries**: the current product is commercial. A 2012
  release is OGL (Edinburgh DataShare / Zenodo) but 14 years stale.
- **OS Code-Point with Polygons**: official, paid, not open.
- **Earthware "Full UK Postcode Polygons"**: commercial derived product.
- **ITSLeeds/OpenPostcodes** and Mark Longair's 2021 unit boundaries: prior
  Voronoi-based open reconstructions; confirm the method is standard.

## Coastline for clipping

- ONS Open Geography Portal "Countries (December 2024) Boundaries UK BGC"
  (generalised to 20 m, clipped to the coastline), served from the ONS ArcGIS
  feature service at `services1.arcgis.com/ESMARspQHYMw9BZ9`. Licence OGL v3
  with OS and ONS attribution. The pipeline locates the newest edition through
  the ArcGIS catalogue search and downloads it as GeoJSON; a fixed URL can be
  supplied instead.
- BFC (full resolution) is available too but is ~10x larger and adds nothing
  visible at the zooms where polygons are shown.
- If no coastline can be downloaded the pipeline falls back to a mask built
  from the postcode points themselves (a dilated 1 km occupancy grid), so it
  never blocks; the result is blobbier at the coast and is flagged in the
  build log.

## Basemap

- **OpenFreeMap "Liberty"** (`https://tiles.openfreemap.org/styles/liberty`):
  free, no API key, OpenStreetMap data, attribution added automatically by
  MapLibre. Chosen default.
- **OS Open Zoomstack** via OS Data Hub Vector Tile API: free tier but needs
  an API key; supported by setting `basemapStyle` in `web/config.js`.

## Tooling

- tippecanoe 2.78 writes `.pmtiles` directly, so no separate conversion step.
- MapLibre GL JS 5.x + `pmtiles` 4.x from npm; Vite for `npm run dev` and a
  static `npm run build`.

## Plan

1. `pipeline/build_points.py`: read Code-Point Open (or ONSPD, or a generic
   `postcode,lat,lon` CSV), normalise the postcode, drop rows without
   coordinates, derive area/district/sector codes, reproject, write one
   canonical `units.csv`.
2. `pipeline/build_polygons.py`: Voronoi of all unit points in EPSG:27700
   (scipy/Qhull), cells assembled with shapely, dissolved to sectors,
   districts and areas with coverage unions, clipped to the coastline mask,
   with label points (pole of inaccessibility) and bounding boxes written to
   properties. Output is newline-delimited GeoJSON.
3. `pipeline/build_tiles.sh`: tippecanoe per layer with min/max zooms aligned
   to the app thresholds, joined into `boundaries.pmtiles` (small) and
   `units.pmtiles` (large).
4. `pipeline/build_index.py`: static search index; one JSON of area/district/
   sector bounding boxes and one small JSON per district for unit lookups.
5. `web/`: MapLibre app with the four zoom-swapped layers, hover, click-to-zoom,
   search, legend and attribution.
6. `Makefile` wires it together; raw and generated data are gitignored.

## Local test run

To validate the pipeline where the OS endpoint was unreachable, it was run on
`dwyl/uk-postcodes-latitude-longitude-complete-csv` (GitHub), an October 2017
extract of the same unit centroids (1.74 M rows, including Northern Ireland),
with the grid-mask fallback because the ONS coastline service was also
unreachable from the sandbox. Full run via `make all SOURCE=csv`:

| Stage          | Result                                                   |
|----------------|----------------------------------------------------------|
| points         | 1,738,088 units kept; 20 unparseable, 135 out of range   |
| polygons       | 10,879 sectors, 2,942 districts, 121 areas in 107 s      |
| tiles          | boundaries.pmtiles 79 MB, units.pmtiles 70 MB            |
| index          | 2,958 district files, 57 MB                              |

The app was exercised headlessly at all four levels, plus search, hover and
click-to-zoom. This snapshot is for testing only; the Makefile default is the
live Code-Point Open download, and `pipeline/README.md` has the timings.
